## 🚀 Featured Projects

### 🧠 NEURONET: AI-Driven Adolescent Mental Health Support
*Capstone project (team lead of 4, graded A+)*

An early-detection and support platform for adolescent mental health, made up of two Flutter mobile apps (adolescent and guardian), a Next.js web portal for administrators and counselors, a FastAPI backend, and a custom-trained AI engine.

`Flutter` `Next.js` `FastAPI` `MongoDB` `AWS` `Railway`

### 🛡️ EthioScan: Web Vulnerability Scanner
*Built at the INSA Cyber Talent Summer Camp*

A web vulnerability scanner that detects common issues such as **XSS, SQL injection, and IDOR**. Designed for low-bandwidth environments, local-language support, and safe testing through allowlisted targets.

`Cybersecurity` `Web Security` `Python`

### 🧩 INSA Personality Testing Platform
A platform that lets organizations assess employee personality using established frameworks (Big Five, Holland, Myers-Briggs, and more). The backend was migrated from Node.js to **Go** to strengthen security.

`Next.js` `Go`

### 📣 INSA Intranet Communication System
An internal communication system for news, announcements, and document sharing.

`React` `Spring Boot` `Java`

### 🎓 Fellowship Management Website
A full-stack site I built solo to replace manual student registration. It is deployed on a custom domain and used in production today.

`Next.js` `Spring Boot`
